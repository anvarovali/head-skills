# HEAD skills · [skills.head.uz](https://skills.head.uz)

Agent skills by [HEAD](https://head.uz) and the AI Praktikum community, for Claude Code, Codex, Cursor, Gemini CLI and 30+ other agents.

[HEAD](https://head.uz) va AI Praktikum hamjamiyati tayyorlagan agent skillʼlari: Claude Code, Codex, Cursor, Gemini CLI va boshqa 30 dan ortiq agent uchun.

Browse and read every skill / Barcha skillʼlar: **https://skills.head.uz**

## Install · Oʻrnatish

**Any agent** (via [`npx skills`](https://github.com/vercel-labs/skills)):

```bash
npx skills add anvarovali/head-skills                          # pick from the list / roʻyxatdan tanlang
npx skills add anvarovali/head-skills -s gauntlet-loop -g      # one skill, globally / bitta skill
```

**Claude Code plugin marketplace:**

```
/plugin marketplace add anvarovali/head-skills
/plugin install gauntlet-loop@head-skills          # one skill / bitta skill
/plugin install praktikum-starter@head-skills      # the AI Praktikum pack / AI Praktikum toʻplami
```

**Claude.ai:** download the skill’s `.zip` from its page on [skills.head.uz](https://skills.head.uz), then upload it in *Settings → Capabilities → Skills*.
Skill sahifasidan `.zip` faylni yuklab oling va *Settings → Capabilities → Skills* boʻlimiga yuklang.

## Contribute · Hissa qoʻshish

Made a useful skill? Open a pull request. Copy [`templates/skill`](templates/skill) to `skills/<your-skill>/`, run `npm run validate:skills`, and follow [CONTRIBUTING.md](CONTRIBUTING.md) (Oʻzbekcha · Русский · English).

Foydali skill yaratdingizmi? [`templates/skill`](templates/skill) papkasini `skills/<skill-nomi>/` ga nusxalang, `npm run validate:skills` bilan tekshiring va pull request oching. Batafsil: [CONTRIBUTING.md](CONTRIBUTING.md).

## Repository layout

| Path | What |
| --- | --- |
| `skills/<id>/SKILL.md` | The skill itself: what agents install |
| `skills/<id>/head.json` | Site metadata (titles per language, category, author); schema in `schemas/head.schema.json` |
| `bundles/<id>.json` | Skill packs, e.g. `praktikum-starter` |
| `.claude-plugin/marketplace.json` | Generated by `npm run catalog`; one plugin per skill and per bundle |
| `scripts/validate-skills.mjs` | The checks every pull request must pass |
| `src/` | The skills.head.uz website (Vite + React) |
